# UWF-HemoDetect 项目摘要

UWF-HemoDetect 关注超宽视野眼底影像中的出血点检测问题。公开整理版保留了模型实验代码、指标可视化结果和项目结构说明，用于展示本科毕业论文阶段的研究与工程实践。

## 研究背景

超宽视野眼底影像能够覆盖更大范围的视网膜区域，对于眼底病变筛查具有潜在价值。出血点检测属于医学图像分析中的细粒度识别问题，受到病灶尺度小、形态差异大、图像质量波动和标注一致性等因素影响。

## 主要工作

1. 阅读并梳理相关文献，理解超宽视野眼底影像特点及其在眼底病变检测中的应用。
2. 整理 UWF-RHS 相关实验代码与医学图像分割模型基线。
3. 对不同模型结果进行指标对比和可视化。
4. 根据实验表现分析后续优化方向。

## 局限

- 公开仓库不包含医学影像数据，因此不能直接复现实验。
- 代码来自毕业论文阶段实验整理，部分脚本仍保留研究探索痕迹。
- 若要作为正式开源项目继续维护，需要进一步统一配置、依赖版本、训练入口和评估脚本。
