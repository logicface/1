# UWF-HemoDetect

**UWF-HemoDetect** 是本科毕业论文项目“基于超宽视野眼底影像的出血点检测方法研究”的公开整理版。项目主要围绕 UWF 眼底影像分割/检测任务，整理了实验代码、模型基线、对比结果图和项目说明。

> 注意：本仓库不包含原始医学影像数据、标注 mask、训练权重、预训练权重、conda 环境、Python 可执行文件或训练日志。公开版本只保留可以展示项目思路和复现实验结构的源码与结果图。

## 项目目标

- 梳理超宽视野眼底影像技术及其在眼底出血点检测中的应用。
- 基于已有医学图像分割模型进行实验测试和对比。
- 评估不同模型在 Dice、准确率、敏感性、特异性等指标上的表现。
- 根据实验结果分析模型改进方向和医学 AI 落地限制。
